# qiangxiaoxia
Remotion视频自动化生产工厂

## 功能特性
- 🎬 基于Remotion的代码化视频渲染
- 🤖 AI自动生成脚本和配音
- 🚀 批量生产短视频，日均产能100+条
- 🔌 无缝对接OpenClaw系统
- 📱 支持抖音/视频号/小红书多平台发布

## 技术栈
- Remotion 4.x
- React 18
- TypeScript
- Node.js 22+

## 快速开始
```bash
# 安装依赖
npm install

# 预览视频
npm run dev

# 渲染视频
npm run render
```

## 项目结构
```
├── src/
│   ├── Root.tsx          # 根组件，定义所有视频合成
│   └── templates/        # 视频模板库
├── render.ts             # 自动渲染脚本
└── package.json
```
